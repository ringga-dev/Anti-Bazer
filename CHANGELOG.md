## [0.1.0] - 2026-10-23

### Added

- Bun and TypeScript application with CLI and HTTP API.
- Platform adapters for authorized social-content collection.
- Explainable content-pattern indicators and aggregate comment stance analysis.
- Comprehensive product, developer, API, platform, and responsible-use documentation.
- MIT licensing, contribution and security policies, and GitHub CI/release workflows.
- GitHub Actions CI for typechecking and tests on Linux and Windows.
- Tag-driven GitHub Releases with version validation, source archives, and SHA-256 checksums.
- Public project metadata and contribution and security reporting guidance.
